## 🤖 Зачем мне Claude

Рутина в логистике — это не «немного скучно». Это **часы** на:

- перепроверку данных в десятках Excel-файлов;
- сверку документов и поиск расхождений;
- однотипные отчёты, которые собираются руками;
- обработку писем, заявок и запросов по шаблону.

Мой план по автоматизации:

```
Забрать у людей монотонность →
Вернуть людям аналитику, решения и развитие →
Зафиксировать работающие схемы в правилах и шаблонах →
Передать их команде
```

### Что уже осваиваю в Claude Code

- 📊 **Обработка Excel** — проверка файлов на ошибки формул (`#REF!`, `#N/A`),
  скрытых строк, объединённых ячеек; объединение данных из нескольких
  источников в один итоговый файл — **без изменения исходников**;
- 📝 **Регламенты для ИИ** — правила проекта (CLAUDE.md), по которым агент
  работает строго по процессу: сначала проверка, потом действие, потом
  независимая сверка результата;
- 📄 **Документы и тексты** — отчёты, инструкции, шаблоны, коммерческие тексты;
- 🔁 **Воспроизводимость** — любое действие оформляется так, чтобы его мог
  повторить каждый сотрудник отдела.

## 🧭 Мои принципы

```text
01. Исходные данные неприкосновенны — правки только в копии
02. Сначала проверить — потом переносить
03. Каждый шаг воспроизводим и документирован
04. Результат всегда сверяется с эталоном
05. Ошибка в документе стоит дороже часа обучения
06. Навык ценен только тогда, когда передан команде
```

## 👥 Передача знаний команде — ключевая цель

Я убеждён: руководитель сильён не тем, что умеет сам, а тем, что умеет его отдел.

Поэтому мои планы по развитию команды:

| Этап | Результат |
|---|---|
| 🎓 1. Освоить самому | уверенная работа с Claude Code на реальных задачах |
| 🧪 2. Обкатать | проверенные сценарии: Excel, документы, отчёты, сверки |
| 📘 3. Оформить | инструкции и шаблоны промптов «под ключ» |
| 🤝 4. Передать | обучение сотрудников отдела на их ежедневных задачах |
| 📈 5. Измерить | часы, сэкономленные отделом, и рост скорости обработки |

**Итог:** команда тратит время на логистику, а не на перетаскивание ячеек.

## 💬 Моя философия

> **ИИ не заменит логиста. Но логист с ИИ заменит логиста без ИИ.**

В международной логистике цена ошибки — деньги, сроки и репутация.
Поэтому скорость здесь важна только вместе с дисциплиной:

```
Скорость ИИ  ×  Проверка каждого шага  =  Надёжная логистика
```
